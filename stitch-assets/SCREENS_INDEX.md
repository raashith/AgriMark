# AgriMark Stitch Screens

The uploaded Stitch package contains the visual/source exports for the complete AgriMark ecosystem. Each screen directory contains the original HTML export (`code.html`) and, where supplied, the corresponding screenshot (`screen.png`).

The interactive runtime is implemented in `stitch-app/` and keeps authentication, API calls, telemetry, and database integration separate from these reference assets.

Use `STITCH_ASSET_MANIFEST.json` for the complete asset inventory and `ROUTE_MAPPING.json` to see the intended app route for each Stitch screen.

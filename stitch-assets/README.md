# AgriMark Stitch Source Assets

This directory contains the complete Stitch-exported HTML screen references and design specifications uploaded for the AgriMark Stitch app.

- 33 Stitch `code.html` screen exports
- Matching `screen.png` visual references where provided
- Stitch design system specifications
- Mobile ergonomics / production UI state / developer handoff documentation

The production application remains the Next.js app in `stitch-app/`. These assets are preserved as source references and are also exposed by the Stitch deployment under `/stitch-assets/` where practical.

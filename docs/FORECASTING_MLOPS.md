# AgriMark Forecasting MLOps & Evaluation Architecture

## Model Types
1. Baseline Statistical (ARIMA, HW)
2. Time-Series (Prophet, N-BEATS)
3. Machine Learning (XGBoost, LightGBM)
4. Hybrid (Ensemble)

## Evaluation Metrics
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- MAPE (Mean Absolute Percentage Error)
- SMAPE (Symmetric MAPE)
- Bias & 95% Confidence Interval Coverage

Champion models are selected based on empirical validation performance without declaring a universal single model.

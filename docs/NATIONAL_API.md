# AgriMark National Control Tower API Reference

## Endpoints
- GET `/api/v1/national/commodities` - National commodities & commodity balance
- GET `/api/v1/national/supply` - Multi-signal supply intelligence
- GET `/api/v1/national/demand` - Multi-signal demand intelligence
- GET `/api/v1/national/prices` - Multi-signal price separation (Mandi, Farmer, Buyer, FPO, AI)
- GET `/api/v1/national/weather` - Verified weather observation feed
- GET `/api/v1/national/climate` - Climate anomaly indices (SPI, drought, flood, heat stress)
- GET `/api/v1/national/production` - National & state crop production statistics
- GET `/api/v1/national/forecasts` - Champion forecast model predictions & MLOps metrics
- GET `/api/v1/national/policy` - Government policy documents & scheme eligibility evaluator
- GET `/api/v1/national/food-security` - Food security composite & component indicators
- GET `/api/v1/national/health` - National control tower system health & quality status

# AgriMark Scheme Intelligence Engine

## Scheme Lifecycle & Statuses
- `ACTIVE`: Current scheme with verified source evidence.
- `UPCOMING`: Officially announced scheme not yet open for applications.
- `EXPIRED`: Application window closed or budget exhausted.
- `SUSPENDED`: Temporarily halted by publisher.
- `UNKNOWN`: Insufficient evidence to verify current status.

## Rule Constraint
AgriMark strictly prohibits marking a scheme as `ACTIVE` without current source evidence from an official primary or secondary portal.

# AgriMark Security & AI Governance Model

## Core Security Safeguards
1. **RBAC & Tenant Isolation**: Strict isolation between Sandbox projects and Production databases.
2. **LLM Write Guard**: LLMs and AI Agents NEVER have direct unrestricted database write access.
3. **No Financial Movement**: AgriMark provides decision support only. It does NOT approve loans, move money, or grant regulated financial certifications.
4. **No Autonomous Physical Execution**: Physical machinery or drones require explicit Stage 21 authorization connectors.
5. **No Biological Release**: Wet-lab operations or physical release of biological organisms are strictly prohibited.

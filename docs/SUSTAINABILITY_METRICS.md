# AgriMark Sustainability Metrics & Provenance

## Multi-Dimensional Metrics
AgriMark explicitly rejects reducing farm sustainability to a single opaque score. The system exposes:
- Water efficiency (%)
- Energy efficiency (%)
- Input efficiency (%)
- Waste diversion (%)
- Soil health index
- Emissions intensity (kg CO2e / kg yield)
- Resource productivity score

## Data Lineage
Every metric persists:
- `source_measurement_ids`
- `normalized_record_id`
- `methodology`
- `methodology_version`
- `factor_version`
- `calculation_version`

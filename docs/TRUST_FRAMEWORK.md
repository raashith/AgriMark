# AgriMark Agricultural Trust Framework

## Overview
AgriMark implements a transparent, multi-signal trust scoring mechanism for farmers, buyers, FPOs, logistics, and quality assayer entities.

## Trust Signals & Weights
1. Identity Verification (20 pts)
2. Farm & Infrastructure Verification (20 pts)
3. Historical Order Fulfillment Rate (30 pts)
4. Quality Assay Pass Rate (15 pts)
5. Clean Dispute History (15 pts)

Score changes include explicit evidence traces explaining why scores increase or decrease.

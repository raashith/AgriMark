# AgriMark National Commodity Balance Architecture

## Balance Formula
```
Closing Stock = Opening Stock + Production + Imports - Exports - Processing - Consumption - Losses
```

## Statistical Nature Classification
Each component is explicitly tagged:
- **OBSERVED**: Direct mandi arrival, customs trade data, or verified warehouse inventory.
- **ESTIMATED**: Statistical crop production estimates from DES or survey data.
- **FORECAST**: Predictive model output.

Estimated values are never presented as official statistics.

# AgriMark Consent & Access Control Model

## Consent Lifecycle
Farmers retain full ownership and control over their private data.
- **Grant**: Farmers grant specific data access permissions to authorized recipients for defined purposes.
- **View**: Farmers inspect active and historic data permissions.
- **Revoke**: Farmers revoke permissions at any time, instantly invalidating access.

## Access Scopes
- `public`
- `community`
- `commercial`
- `research` (Requires automated PII stripping & coordinate blurring)
- `private`
- `regulated`

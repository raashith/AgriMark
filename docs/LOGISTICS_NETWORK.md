# AgriMark Regional Logistics Network Specification

## Overview
Coordinates fleet providers, mini-trucks, refrigerated transport, pickup hubs, and cold storage facilities.

## Immutable Milestone Events
Events recorded in `logistics_shipment_events`:
- `pickup_assigned`
- `picked_up`
- `in_transit`
- `arrived`
- `delivered`

API Endpoint: `/api/v1/logistics`

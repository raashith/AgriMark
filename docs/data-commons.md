# National Agricultural Data Commons Architecture

## 1. Overview
AgriMark Data Commons is a federated, consent-aware, purpose-limited data exchange fabric that connects farmer systems, FPOs, state/central platforms, research institutions, markets, logistics, banks, insurers, and AgTech providers.

## 2. Core Principle
Separates Data Ownership, Custody, Access, Processing, Sharing, and Derivation. Possession of data does NOT constitute ownership.

## 3. Data Layers
- Identity, Registry, Geospatial, Crop, Soil, Weather, Climate, Market, Price, Supply, Demand, Logistics, Storage, Processing, Finance, Insurance, Policy, Research, IoT, Satellite, Drone, Machinery, Execution, Outcomes.

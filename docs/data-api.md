# Data Commons API Specification

## Endpoints
- `/api/v1/data/catalog` - Search & explore national data catalog
- `/api/v1/data/providers` - Data provider registry
- `/api/v1/data/consumers` - Data consumer registry
- `/api/v1/data/schemas` - Canonical schema registry
- `/api/v1/data/contracts` - Data contracts lifecycle
- `/api/v1/data/consent/grant` - Grant purpose-limited consent
- `/api/v1/data/consent/withdraw` - Withdraw consent
- `/api/v1/data/lineage/forward/{id}` - Forward lineage graph
- `/api/v1/data/lineage/reverse/{id}` - Reverse lineage graph
- `/api/v1/data/exchange/process` - Data Exchange Gateway pipeline
- `/api/v1/data/sandbox/datasets` - AI Dataset Builder & Research Sandbox

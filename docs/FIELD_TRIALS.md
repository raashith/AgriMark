# AgriMark Field Trial System & Experiment Assistant

## Trial State Machine
`PROPOSED` → `IN_PROGRESS` → `COMPLETED` → `VALIDATED`. Incomplete experiments are never represented as validated results.

## Farmer Learning Trials
Allows controlled farmer-led A/B trials (comparing irrigation or fertilizer strategies) requiring a control group, measurement period, data collection, and safety constraints. Dangerous chemical or unvalidated biological experiments are strictly blocked.
